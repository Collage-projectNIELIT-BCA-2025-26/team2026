# BCA Team Project 2026

This is a web project for the NIELIT-BCA-2025-26 course.

## Project Structure

- `index.html`: Main landing page of the project.
- `sign_in.html`: User login page.
- `sign_up.html`: User registration page.
- `styles.css`: Central stylesheet for all pages.
- `script.js`: JavaScript for interactive elements.

## Optimized Features

- Semantic HTML structure.
- Organized folder structure for easy navigation.
- Consolidation of styles for consistency.
